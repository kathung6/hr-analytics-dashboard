# HR Analytics Dashboard (Power BI)
![Dashboard Preview](dashboard_preview.png)
## Features

Cards:
  - Total Employees
  - Average Tenure
  - Turnover Rate
Visuals:
  - Line Chart: Hires vs. Terminations Over Time
  - Bar Chart: Headcount by Department
  - Pie Chart: Attrition Type
  - Interactive Slicers

## Tools Used:
- Power BI
- PostgreSQL
- Python (to generate mock data)
- SQL

## Insights
- 26% turnover rate over all the data
- Average tenure of 19.3 months
